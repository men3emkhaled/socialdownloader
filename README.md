# Social Media Downloader Bot

بوت تليجرام لتحميل الفيديوهات من السوشيال ميديا (فيسبوك، تيك توك، إنستجرام، إلخ) باستخدام `yt-dlp`.

## المميزات
- دعم آلاف المواقع.
- خفيف جداً ومناسب لـ Railway.
- مسح تلقائي للفيديوهات بعد إرسالها لتوفير المساحة.
- حفظ بيانات المستخدمين في قاعدة بيانات Neon.

## كيفيه التشغيل محلياً
1. ثبت المكتبات:
   ```bash
   pip install -r requirements.txt
   ```
2. انسخ ملف `.env.example` إلى `.env` وحط التوكن بتاعك:
   ```bash
   cp .env.example .env
   ```
3. شغل البوت:
   ```bash
   python main.py
   ```

## الرفع على Railway و Neon
1. افتح [Railway](https://railway.app/) واعمل مشروع جديد.
2. اربط المشروع بالـ GitHub repository بتاعك.
3. في الـ **Variables** ضيف:
   - `BOT_TOKEN`: التوكن من BotFather.
   - `DATABASE_URL`: اللينك اللي هتاخده من **Neon.tech** (PostgreSQL).
4. الـ Railway هيقرأ الـ `Dockerfile` أوتوماتيك ويشغل البوت.

## ملاحظات هامة
- التليجرام بيسمح للبوتات برفع ملفات حجمها أقصى حاجة **50 ميجا**. لو الفيديو أكبر من كدة البوت هيطلع رسالة تنبيه.
- البوت بيمسح الفيديو من السيرفر فوراً بعد ما يبعتهولك عشان يحافظ على مساحة السيرفر.
